# WLPay Landing

Одностраничный лендинг WLPay — open source P2P-платформы для трейдерских команд, мерчантов и процессинга.

## Локальный просмотр

Откройте `index.html` в браузере или запустите простой сервер:

```bash
python3 -m http.server 8080
```

После этого откройте `http://localhost:8080`.

## Файлы

- `index.html` — разметка, стили и интерактивность.

## Telegram

В коммерческом режиме пока установлена неактивная заглушка. Когда появится контакт, замените ссылку с классом `telegram-placeholder` на адрес вида `https://t.me/username` и удалите `aria-disabled="true"`.
